## Overview

**SG-NTF** is a neural low-rank tensor completion model based on Tucker decomposition, incorporating **Fourier feature mapping** and **context-aware gating** to model multi-mode interactions. Experimental settings follow standard sparse tensor completion protocols (see [Tang et al., *IEEE TKDE* 2025](https://doi.org/10.1109/TKDE.2025.3590198)).
